# C-Tab 新标签页

一个美观、功能丰富的新标签页扩展，支持自定义快捷方式、分类管理、主题切换等功能。

## 加载扩展到Edge浏览器

1. 打开Edge浏览器，进入扩展页面（edge://extensions/）
2. 开启右上角的"开发人员模式"
3. 点击"加载已解压的扩展"按钮
4. 选择项目目录中的`extension`文件夹
5. 现在，每次打开新标签页时，就会显示我们的自定义新标签页

## 注意事项

- 如果您在Windows系统上遇到任何命令执行问题，请确保您的Node.js版本是最新的
- 扩展使用localStorage存储数据，确保浏览器允许使用localStorage
- 如需查看或修改扩展的配置，请在新标签页中点击右上角的设置图标

## 功能特色

- 自定义快捷方式管理
- 分类系统，方便组织不同类型的网站
- 暗色/亮色主题切换
- 自定义图标尺寸、圆角和间距
- 响应式设计，适配不同屏幕尺寸
